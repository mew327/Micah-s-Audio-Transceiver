# Draft receiver enclosure

Two STL files, in millimetres: receiver_base.stl and receiver_lid.stl.
Assembled outside dimensions: 100 x 75 x 30 mm.
Base walls/floor: 2 mm. Open base cavity: 96 x 71 x 26 mm.
The lid skirt occupies the upper 3 mm of the cavity around its perimeter.
Lid skirt clearance: 0.3 mm per side, skirt wall: 1.2 mm.

Print each part as supplied: base floor on bed; lid flat outer face on bed,
skirt upward. Flip the lid for assembly. No supports should be needed.
Suggested starting settings: ordinary PLA or PETG, 0.2 mm layers, 3 perimeters.
Actual fit depends on printer calibration; this is an unprinted draft.
The lid is a removable slip fit, without a latch or screws; retention is not guaranteed.

No connector cutouts, PCB posts, battery restraint, or screw holes are included.
Do not use this draft to determine the final antenna clearance or usable PCB size.
Select actual components and antenna layout before final mechanical design.
There is no battery compression or retention feature; add a suitable holder later.

Editable parametric source: receiver_enclosure.scad (OpenSCAD).
STLs generated by generate_enclosure.py; both meshes checked for closed edges,
consistent face winding, nonzero triangles, and positive signed volume.
